# Loan Calculator 🏦

Calculate monthly payments, total interest, and amortization schedules for any loan.

## Features

- Monthly payment calculator
- Total interest and total cost breakdown
- Amortization schedule (month-by-month breakdown)
- Support for different loan types (mortgage, auto, personal)
- Adjustable interest rate and term
- Visual pie chart of principal vs interest
- Mobile-friendly responsive design

## Formula

Monthly Payment = P × [r(1+r)ⁿ] / [(1+r)ⁿ - 1]

Where:
- P = Principal (loan amount)
- r = Monthly interest rate (annual rate / 12)
- n = Number of payments (months)

## Usage Examples

- $200,000 mortgage at 5% for 30 years → $1,073.64/month
- Total interest: $186,511.57
- $25,000 auto loan at 4.5% for 5 years → $466.08/month
